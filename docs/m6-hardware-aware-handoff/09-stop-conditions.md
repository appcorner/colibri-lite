# Stop Conditions

Stop and request review when a candidate changes public cross-crate contracts,
needs unsafe code or a material dependency, alters artifact compatibility,
cannot meet the F32 comparison contract, changes safe-margin routing IDs,
misses quality gates, exceeds a budget, relies on swap, or lacks repeatable
end-to-end improvement.

Do not expand a failed M6.3 slice to all 48 layers. Record rejected candidates
in the backlog with measured evidence and a precise reconsideration condition.
