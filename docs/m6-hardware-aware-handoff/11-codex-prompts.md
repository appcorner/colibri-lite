# Implementation Prompts

Use a focused prompt per task: state the exact task ID, applicable reference
artifacts, allowed files, acceptance criteria, required commands, and that the
F32 oracle must remain unchanged. Require a concise evidence report with
completed tasks, changed contracts, commands/tests, benchmark data, open
issues, and the exact next task.

For M6.3 additionally require direct-quantized-consumption proof, provenance,
dependency/unsafe review, first-divergence report, bilingual quality results,
and repeated cold/warm measurements before requesting a go decision.
