# M6.0 Reference Contract Baseline

M6.0 closes the reference boundary before hardware profiling and planning.
The verification baseline pins `reference-f32-v1`, the bilingual quality
fixtures, and the M4 F32 performance record. It is deliberately not a new
hardware, memory, I/O, or throughput measurement.

The contract validator has deterministic success, wrong-reference-ID,
corrupted-hash, and changed-expected-output tests. Its inputs remain small
tracked metadata/evidence files; it copies no model payload.

The next task, M6.1-01, defines profile schemas. It must collect new machine
measurements rather than reusing this historical M4 performance evidence.
