# M6.3-R2.2-D5 Production Hybrid Protocol

D5 promotes the D4D4 quality-valid sentinel policy into a production-like representation before any runtime-value claim.

Phase 1 builds and freezes Layer24 hybrid expert storage containing canonical F32 gate/up plus packed group8 down. The candidate must directly consume this layout without reconstructing a complete F32 down matrix or whole F32 expert. Layer0 reuses its frozen group32 artifact. Layer47 and all other layers remain canonical F32.

Phase 2 reruns the exact D4D4 bilingual quality gates through the production-like path. Failure stops D5 before official performance timing.

Phase 3, if quality passes, runs 40 fresh process samples: short English and Thai x first-process-touch and likely-warm labels x five balanced F32/hybrid pairs x two paths. Cache labels describe observed software/process state and do not imply controlled cold-device I/O.

Primary runtime metrics are wall time, prefill/decode throughput, peak working set, peak private bytes, logical artifact bytes, expert payload bytes, and candidate artifact bytes. Physical I/O is not inferred from logical reads.

The frozen GO rule requires >=1% median wall-time speedup in each fixture, >=4/5 hybrid pair wins in every fixture/cache-label cell, <=1% working-set/private-byte regression, and positive logical expert-byte reduction.

No automatic retry, post-result retuning, new precision, native group8 kernel, cache-policy change, historical R2.2c reuse, all-layer rollout, or M6.4 implementation is allowed.
