## Contract

`scripts/m6_3_r1_1a_cold_cache.py` implements three operations:

1. `prepare` performs the only pre-reboot full hash and writes immutable
   artifact identity evidence.
2. `arm` proves a reboot, checks metadata only, and writes a one-shot token.
3. `verify-launch --consume` atomically consumes that token in the same boot
   before the ETW collector starts its trace.

The candidate ETW configuration must add
`COLIBRI_R1_1A_COLD_CACHE_AUTHORIZATION` to both `environment` and
`required_environment`. `-ValidateConfigOnly` checks that binding and the
candidate/artifact path relationship without consuming the token. Actual
elevated capture validates and consumes the token before ETW launch.
