## Resource gates

The validator confirmed zero complete F32 weight materializations, zero
persistent native prepack, zero VRAM use, compute-only zero load bytes, and the
frozen candidate/reference logical payload accounting. The candidate artifact
remained unchanged at `679,477,248` bytes.

## Decision

R2.1 closes `GO`. The result validates that the native packed projection removes
the previously localized scalar packed-projection compute tax for the Layer-0
vertical slice while retaining the group32 byte/load advantage and held-out
quality envelope.

The next authorized activity is `M6.3-R2.2` **design only**. R2.2 must model and
pre-register how to expand proof beyond Layer 0 before any additional layer is
converted or executed with the candidate. M6.4 and production/all-layer rollout
remain blocked.
