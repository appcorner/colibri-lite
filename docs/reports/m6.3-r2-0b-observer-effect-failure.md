# M6.3-R2.0b Observer-Effect Gate Failure

## Status

The reference-only fixture and execution identities were frozen before the first
candidate observer-control timing. The frozen release binary then completed all
40 pre-registered observer-control process executions (20 paired controls).

The control set is invalid for authorizing R2.0 localization because the F32
reference instrumentation exceeds the unchanged observer-effect limits. No
R2.0 localization sample has been executed.

All enabled/disabled paired outputs were byte-identical. The failure is therefore
measurement observer overhead, not a numerical-output divergence.

The F32 path performs fine-grained `Instant` start/elapsed observations around
interleaved gate, up, activation, and down row operations. This produces many
clock reads in the timed path. Candidate projection timing is coarser and passes
the same gate on both fixtures.

## Decision

- R2.0c remains blocked.
- The failed control set is never retried or reclassified as passing evidence.
- No threshold, fixture, stage family, pair order, iteration count, or
  classification rule may be changed to accommodate this result.
- Any measurement-only remediation requires a new append-only preregistration
  before implementation and before another candidate timing process.
