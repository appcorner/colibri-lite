# M6.0-04 Frozen Bilingual Quality Fixtures

This task promotes two existing Tier-B F32 reference cases into the explicit
M6 quality-fixture set without running the model again or changing any
numerical criterion.

| Fixture | Input token IDs | Expected argmax | Coverage |
| --- | --- | ---: | --- |
| `short_english` | `[9707, 1879]` | `0` | English, complete F32 forward |
| `short_thai` | `[125451]` | `7360` | Thai, high token ID, complete F32 forward |

The manifest freezes input text/token IDs, final-position metadata, F32
final-norm digest, safe-margin router IDs at layers 0/24/47, compact reference
logits, top-20 IDs, finite counts, and top-1 margin. It pins the
`reference-f32-v1` manifest, Transformers F32 Tier-B evidence, Rust F32
comparison evidence, and the existing tolerance registry by size and SHA-256.

These are reference outputs, not newly broadened acceptance thresholds.
M6.3 must define any quantized/backend candidate quality thresholds in a
separate reviewed decision.
