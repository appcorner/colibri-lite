## Future evidence workflow

Each unmeasured layer must independently pass the frozen characterization grammar before it can become a non-F32 candidate. Complete group32 is diagnostic only. Projection sensitivity uses the same seven D3 subsets when needed, and group32/group16/group8 are tested independently because D2 showed precision error is not monotonic with group size. A selected layer must then pass sequence-aware validation.

Cumulative interactions are handled explicitly. Eligible layers are ranked by worst sequence-aware local error divided by logical bytes saved, tie lower layer ID, then added in fixed batches of four. Every batch reruns full-model bilingual quality. Failed batches are bisected deterministically; an individually failing layer falls back to F32 for the contract with no threshold or precision retry.

## Quality, layout, and performance boundaries

The future cumulative candidate must pass at least the accepted D5b exact semantic gates before performance. Production artifacts must directly consume only admitted representations and may not reconstruct complete F32 candidate projections or whole F32 experts for convenience. Every artifact requires a frozen layout/SHA and explicit backend/F32 fallback.

Official all-layer timing remains blocked until cumulative quality passes and a separate performance contract is frozen. The future proof must use fresh paired processes, balanced order, bilingual workloads, memory peaks, wall/prefill/decode throughput, and logical bytes. Physical SSD attribution is not allowed without separately revalidated Windows telemetry.

A storage-only mathematical ceiling of `80,379,641,856` bytes (`69.314236111111%`) would require the purely hypothetical assumption that all 45 unmeasured layers admit complete group32 while Layer47 remains F32 and Layer24 keeps its validated hybrid. It is recorded only as an arithmetic ceiling, not as a candidate or expected result.

The review is therefore complete without overstating the evidence. The next authorized work is design of the exact R2.3 implementation contract; implementation itself remains blocked.
