# M6.0-01 Reference F32 Freeze

`reference-f32-v1` freezes the existing M4 F32 runtime as the differential
oracle for M6 candidate backends. It does not duplicate model payloads or
change execution behavior. The manifest pins the M4 release provenance,
canonical artifact identity, numerical tolerance registry, Tier A deterministic
generation, intermediate checkpoints, and Tier B English/Thai coverage.

The reference uses BF16 source weights converted to F32 storage and safe,
ordered scalar F32 arithmetic. Its release identity is
`colibri-lite-rs-m4-qwen3-30b-a3b-f32-v1` at
`m4-full-qwen3-baseline-v1`. Historical performance is evidence only; it must
not be reused as a hardware-profile measurement.

Verify the freeze with:

```powershell
python -m unittest python.reference.test_reference_f32_manifest
```

Any candidate backend must validate every `integrity_records` entry before
comparison and report its first divergent stage against the referenced
tolerance contract.
