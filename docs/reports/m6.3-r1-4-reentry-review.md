# M6.3-R1.4 Re-entry Review

## Decision

`NO-GO for promotion` of `cpu-safe-rust-int8-group32-layer0-r1-1a` beyond the measured Layer-0 slice.

R1.2 quality remains valid. R1.3 measurement is also valid. The rejection is therefore not a correctness rejection; it is a runtime-value decision under the pre-registered promotion boundary.

## Evidence considered

- R1.2 quality result SHA-256 `51777c84beb4e9c918acfc62338046e820b8bb3d64da904e7248f3e752e1d27e`
- R1.3 20-sample set SHA-256 `4995c01a36c93023ed886108a9368b45746a4f6c2f015e2c0e6cfcbc72e5bea4`
- R1.3 paired result SHA-256 `491ea0490e400e6563807ec9000eee2cbe78f908d5c4ce709ef18b5f32f2d04b`
- R1.4 decision record SHA-256 `49e470254afb64cbd40426f0c833eff57e9ce787f28f638ecd7ab2ff98ada041`

The candidate has one repeatable benefit: total logical bytes are 0.8919485285% lower in all five cold and all five warm pairs.

It does not have a repeatable latency or throughput benefit. Candidate median timed wall is `+2.8183%` cold and `+8.7446%` warm; TTFT is `+9.1717%` and `+7.4820%`; decode throughput is `-3.4114%` and `-6.6696%`.

Working set and private bytes are effectively flat/slightly worse, while physical I/O is dominated by observed OS-cache state and does not satisfy the 5/5 directional rule.

## Review conclusion

The current packed group-32 representation is numerically acceptable but the direct safe-Rust consumption/dequantization path does not deliver material runtime value. Expanding this exact path to 48 layers would be an extrapolation unsupported by the measured evidence.
## Milestone effect

The current M6.3-R1 re-entry path is closed. M6.4 remains blocked and no all-layer candidate plan is authorized from this result.

The useful lesson is narrower: representation-byte reduction alone is not the current bottleneck. A future proposal should target the consumption cost or scheduling path directly, for example optimized native dequant/GEMM, measured I/O-compute overlap, or hardware-aware expert placement. Such work requires a new pre-registered hypothesis and cannot inherit a promotion decision from this candidate.

ADR 0078 records this decision without modifying the historical R1.2 quality `GO` or the original group-128 `NO-GO`.
