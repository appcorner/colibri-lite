# M6.3-R1.1a code_newline control calibration

## Outcome

The R1.1a canonical F32 control is calibrated for the frozen `code_newline`
fixture. This closes the fixture-linkage defect that applied ADR 0024's
M4.2-fixture-specific numbers directly to a different input. It does not admit
or execute a candidate and does not authorize R1.2.

ADR 0064 and calibration plan commit
`a44e75c5a55dcf9812d8dbfc360db8049c70a12d` pre-registered the unchanged M4.2
formulas before these two measurements. Both independent release processes
passed every internal exact gate, produced the same checkpoint SHA-256
`a9ba90e1af1622d8308a6355f4f30808806f31fa1bfc94eec652b402704ada11`,
and stayed inside the frozen final-logit budget.
