# M6.3-R2.2 Multi-layer Sentinel Proof Protocol

## Goal

Determine whether the validated R2.1 group32 + AVX2+FMA path generalizes beyond
Layer 0 before any all-layer candidate is designed or built.

Sentinel layers are frozen as `0`, `24`, and `47`. They represent early,
middle, and final MoE depth and already participate in the held-out router guard
contract. All non-sentinel layers remain canonical F32.

Contract:
`models/qwen3-30b-a3b/m6.3-r2-2-multilayer-sentinel-proof-contract-v1.json`
SHA-256:
`3071f717b9ea12091323e596b9a3d40aa776b34f27f0cc66db63774e493af0c4`.

## R2.2a artifact and reader generalization

Create independent group32 artifacts for Layers 24 and 47 using the exact R1.1
conversion grammar. Layer 0 remains the already admitted representation. Freeze
source/output identities before candidate execution.

Generalize only the candidate reader/orchestration needed to select an explicit
verified artifact by layer ID. Reuse the R2.1 kernel and FFI unchanged.
## R2.2b held-out quality

Run both held-out fixtures with native group32 active only at Layers 0/24/47.
Require exact two-token generation, prompt top-20/argmax, Layers 0/24/47 router
IDs, and repeatability. Retain the original F32 <=`0.05` logit envelope and
quarter-margin rule.

For each sentinel layer, native-vs-scalar routed-output max-abs must be
<=`0.001`. End-to-end native-vs-scalar prompt-logit max-abs must remain
<=`0.002`. Any quality failure closes R2.2 before official performance timing.

## R2.2c official compute proof

After quality PASS, freeze one release binary containing native group32, scalar
group32, and F32 paths. Run 108 fresh process samples:

- 3 sentinel layers;
- 2 held-out fixtures;
- all 6 balanced triplet orders;
- 3 paths per triplet.

Each layer/fixture independently requires native > scalar in >=5/6 triplets,
median scalar/native >=`1.50x`, median native/F32 <=`1.05`, and native/F32
<=`1.10` in >=5/6 triplets. No results-based retries or layer reselection.
## R2.2d impact review

Publish the measured per-sentinel distributions, the worst sentinel compute
ratio, 48-layer artifact byte scaling, and explicit uncertainty. R2.1 load-plus
evidence may be used as an input because R2.2 does not change the packed
representation or load semantics, but it may not be relabeled as a measured
multi-layer result.

A complete PASS authorizes `R2.3` all-layer **plan design only**. It does not
authorize a 48-layer candidate build, R2.3 implementation, M6.4, or a production
speedup claim.
