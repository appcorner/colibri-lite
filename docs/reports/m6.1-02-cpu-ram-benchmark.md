# M6.1-02 CPU kernel and RAM bandwidth benchmark

## Scope

This records the controlled baseline required by M6.1-02. It is evidence for
the future hardware profile and planner; it is not an inference-throughput
claim and it does not select a CPU, GPU, SIMD, or FFI backend.

sample distributions so later work can account for this variation rather than
treating a single value as a hardware guarantee.

The machine-readable source is
[`m6.1-02-cpu-ram-benchmark-v1.json`](../benchmarks/m6.1-02-cpu-ram-benchmark-v1.json).
It records warm-ups, repetitions, clock, samples, checksums, and limitations.

## Interpretation and limits

The CPU result is a safe-Rust matrix-vector microbenchmark only. Compiler
optimization remains part of the release build, but no explicit SIMD, unsafe
code, FFI kernel, or backend selection was introduced. The RAM value is a
streaming-copy throughput proxy; it is neither random-access latency nor a
prediction of model-weight I/O. SSD and host/device-transfer measurements are
reserved for M6.1-03 and M6.1-04.

## Reproduction and validation

```powershell
.\scripts\measure_m6_1_02_cpu_ram.ps1
python python\reference\validate_m6_1_02_cpu_ram_benchmark.py `
  --input docs\benchmarks\m6.1-02-cpu-ram-benchmark-v1.json
```

The validator rejects absent results, fewer than three samples, non-finite or
non-positive values, unsorted samples, and invalid percentile ordering.
