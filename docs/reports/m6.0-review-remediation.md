# M6.0 Review Remediation

The M6.0 review found two P2 correctness gaps. Both are resolved and were
verified on commit `84f0cff09ed089f4bae84652f9dd800b05ac8990`.

| Finding | Resolution | Evidence |
| --- | --- | --- |
| A finite tolerance term could yield an infinite allowed error for a finite reference value. | The comparator now rejects a non-finite calculated allowance with a structured `BackendContractViolation`. | A dedicated `f32::MAX` overflow test passes. |
| The cross-contract validator did not compare frozen finite counts with Tier-B source evidence. | The validator now compares NaN, positive-infinity, and negative-infinity counts; an altered count fails. | Dedicated failure-mode test passes. |

Reverification passed 21 Python contract/oracle tests, 136 Rust workspace
tests, formatting, workspace check, Clippy with warnings denied, and the CLI
smoke command. M6.0 is accepted; the next task is `M6.1-01`.
