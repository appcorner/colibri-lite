# M6.1-06 profile validation

## Result

M6.1 profile validation is complete. The tracked doctor and model profiles
validate against their Draft 2020-12 schemas. Invalid profile inputs fail with
the CLI error exit code, and identical explicit inputs produce byte-identical
JSON on repeated execution.
