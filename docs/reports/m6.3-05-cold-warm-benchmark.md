# M6.3-05 Layer-0 Group-128 Cold/Warm Benchmark

## Scope and method

This measures the M6.3 Layer-0 group-128 candidate on the frozen
`short_english` token sequence `[9707,1879]`. Each position executes all 48
layers and a language-model head; position 0 is the first-token/TTFT proxy and
position 1 is a cached-decoder-step proxy. The fixed second input token does
not change the computation shape, but this is not a broad generation
benchmark.

Each of the three independent release processes created the temporary
622,854,144-byte Layer-0 artifact before timing, then measured one pair:

- `runtime_cache_cold`: clear the candidate's selected-expert cache;
- `runtime_cache_warm`: retain that cache in the same process.

Artifact conversion is excluded from both timing samples. The F32 router,
norms, attention, residuals, cache, and Layers 1--47 expert path remain
unchanged. The candidate cache is only the direct group-128 Layer-0 expert
payloads selected by the fixture.

Windows filesystem-cache eviction was not requested. Therefore `cold` means a
cleared runtime candidate cache, not cold-device I/O. Physical per-process disk
read bytes are `not_measured`; all byte metrics below are explicit logical read
accounting. VRAM is zero because no GPU backend is admitted by M6.3.

Every sample requested 9,839,435,776 dense logical bytes and
14,193,524,736 F32-expert logical bytes. Candidate payload residency peaked at
68,124,672 bytes, the F32 expert cache peak was 18,874,368 bytes, and the
two-token KV cache was 393,216 bytes. Their explicit payload accounting total
is 87,392,256 bytes; it is not a process working-set measurement.

## Result and limitation

The warm candidate avoids all 68,124,672 logical bytes of Layer-0 candidate
payload reads in this fixture and increases total expert-cache hit rate. It does
not establish a material end-to-end throughput gain: the median decode rate is
still about 0.021 tok/s and the remaining 47 scalar F32 layers dominate the
work. No physical per-process disk I/O or process working-set peak was captured,
and no GPU/VRAM backend exists. These omissions, together with the M6.3-04
English logit drift, must be treated as stop/go evidence in M6.3-06, not hidden
as a promotion result.

## Reproduction

```powershell
$env:COLIBRI_M63_BENCHMARK_REPETITIONS = '1'
cargo test -p clr-qwen3-moe --release --features full-model-validation -- `
  m6_3_05_layer0_group128_cold_warm_benchmark --nocapture
```

Run this command three times with distinct preflighted run directories; the
harness excludes conversion from timing and removes each run directory on
success.
