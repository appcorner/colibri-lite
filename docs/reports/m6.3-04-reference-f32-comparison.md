# M6.3-04 Layer-0 Group-128 Comparison Against `reference-f32-v1`

## Scope

This validation evaluates only the accepted M6.3 Layer-0 candidate from ADR 0057: symmetric INT8 input groups of 128 with F32 per-row/per-group scales. Layer 0 experts consume the INT8/scales directly in the safe scalar Rust loop. The router, all norms, attention, residuals, cache, Layers 1--47 experts, final norm, and language-model head remain on the independently executable F32 path.

The comparison uses the frozen `reference-f32-v1` canonical root manifest `f133d733612840ad691d637732d4ef2de1e0242c4bb1d92521b49dfcfb1b8cd2`, model revision `ad44e777bcd18fa416d9da3bd8f70d33ebb85d39`, and the frozen English and Thai Tier-B fixtures.

## Interpretation and limit

The two frozen bilingual fixtures preserve routing, greedy output, and all twenty frozen top-logit IDs. The numeric drift is intentionally reported rather than hidden behind an F32 fixture tolerance: that tolerance registry applies to the reference path, not a quantized candidate. In particular, the English fixed-logit drift is material relative to F32 numerical noise.

This is comparison evidence, not an admission to an all-layer rollout or a throughput claim. M6.3-05 must measure repeated cold/warm behavior, RAM, physical I/O, and bytes/token. M6.3-06 must make the explicit stop/go decision using those measurements and this recorded quality evidence.
