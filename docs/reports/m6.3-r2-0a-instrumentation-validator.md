## Instrumentation boundary

The new Cargo feature `m6-3-r2-localization` is test-binary-only. Disabled default builds do not include the collector module. Within an enabled test binary, the same runtime can switch observation on or off for observer-effect controls.

Instrumentation brackets existing operations in place. It does not duplicate, replace, reorder, vectorize, thread, or otherwise change the measured compute loops.
## Collected stages

Common routing records `expert_total`, `routing_occurrence_scan`, `weighted_accumulation`, expert occurrences, and unique expert loads.

F32 records `cache_lookup_load`, `f32_payload_decode`, `gate_projection`, `up_projection`, `activation_product`, and `down_projection`. The interleaved F32 gate/up loop keeps its original arithmetic order; per-row `Instant` samples are accumulated locally and batch-committed to avoid per-row map/collector overhead.

Group-32 records `seek`, packed-value read/decode-validation, scale read/decode-validation, gate/up/down packed projection, and activation/product. Packed projection remains the existing fused scalar dequant-plus-dot operation; no standalone dequant stage is invented.

The hierarchical collector records calls, total/exclusive/min/median/max nanoseconds, logical bytes, counters, and explicit parent residual. A no-op scope calibration supplies the 20x interpretability threshold.
## Validator

`scripts/validate_m6_3_r2_0_localization.py` enforces the frozen contract before classification. It requires the exact 40-sample matrix and pair order, 20 observer-control pairs, same binary/host identities, no automatic retry, exact logical-byte accounting, compute-only zero-read semantics, registered stage names, and exact parent/child timing reconciliation.

Uninterpretable child scopes are merged into residual rather than timer-corrected. A scope named as standalone dequantization is rejected. The validator applies ADR 0079 classification thresholds and can authorize only R2.1 hypothesis design.

Synthetic tests exercise all four classifications plus wrong contract, observer overhead/output failures, pair-order/retry violations, compute-only reads, timing reconciliation, and prohibited dequant evidence.
