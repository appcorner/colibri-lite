# M6.3-R2.1 Native Packed Projection Vertical-Slice Protocol

## Goal

Test whether the R2.0 compute bottleneck can be removed by changing only the
packed group32 projection backend, while retaining the verified group32
artifact, Rust orchestration, quality envelope, and load advantage.

Contract:
`models/qwen3-30b-a3b/m6.3-r2-1-native-packed-projection-contract-v1.json`
SHA-256:
`76bfc4a850a8d89fb5901eda338568b7226b36acb7207324575568ea21f6cc2a`.

R2.0 evidence motivating the proof:

- scalar group32 compute-only median slowdown: +77.35% English, +85.79% Thai;
- candidate slower than F32: 5/5 pairs for each fixture;
- packed gate/up/down share: 91.44% English, 92.04% Thai;
- load-plus candidate faster than F32: 5/5 for each fixture.
## R2.1a implementation boundary

Implement one native AVX2+FMA projection kernel for Windows x64. It consumes
the original `i8` values and `f32` group scales directly and writes one f32
output vector. It does not own Rust allocations and does not expose a public
unsafe API.

Rust keeps routing, expert loading, artifact validation, activation, weighted
accumulation, backend selection, feature detection, and fallback. Native code
replaces only gate/up/down packed projection arithmetic.

Before adding the build dependency, record the exact dependency review. The
pre-registered candidate is `cc = 1.4.4` as build-only infrastructure, licensed
MIT OR Apache-2.0 with MSRV 1.65. The global unsafe lint remains enabled as
`deny`; a local allow is permitted only for the reviewed FFI module.

Required safety tests include invalid dimensions/lengths, unsupported-feature
fallback, finite input/scale validation, output canaries/bounds, repeated calls,
and scalar fallback equivalence. No Rust pointer arithmetic is allowed.
## R2.1b quality gate

Run quality before official performance measurement. Both held-out fixtures
must preserve the exact two-token sequences (`[0,358]` English, `[7360,91]`
Thai), prompt top-20 IDs/argmax, router guards at layers 0/24/47, exact two-run
repeatability, and the original R1.2 F32 logit envelope <=0.05 plus its frozen
top-1 margin rule.

Native versus scalar group32 must additionally remain <=0.001 max-abs at the
Layer-0 routed output and <=0.002 at prompt logits. All outputs must be finite,
artifact identity must remain exact, and complete F32 weight materializations
must remain zero.

Any failure ends the candidate before official performance timing.

## R2.1c performance gate

Freeze one release binary containing all three selectable paths. For each of
two fixtures and two views, execute all six permutations of native/scalar/F32.
This yields exactly 72 official process samples. No retry is allowed merely
because a measurement is unfavorable.
Compute-only PASS requires, for each fixture: native beats scalar in >=5/6,
median scalar/native speedup >=1.50x, native/F32 median ratio <=1.05, and
native/F32 ratio <=1.10 in >=5/6 triplets.

Load-plus PASS requires, for each fixture: native beats scalar in >=5/6,
median scalar/native speedup >=1.25x, native beats F32 in 6/6, and native/F32
median ratio <=0.50. The candidate byte path must remain unchanged; OS file
cache remains uncontrolled/observed and no physical-I/O claim is made.

Resource guard: no complete F32 weight materialization, no persistent native
prepack, no VRAM, and <=1 MiB additional native scratch per projection call.

## R2.1d review

All quality/resource/performance gates must pass before the hypothesis can move
forward. PASS authorizes R2.2 **design only**. It does not authorize R2.2
implementation, M6.4, or all-layer rollout. Failure closes the AVX2+FMA
candidate or requires a new pre-registered compute hypothesis.
