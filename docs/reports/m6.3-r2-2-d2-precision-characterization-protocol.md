# M6.3-R2.2-D2 precision characterization protocol

Contract SHA-256:
`ea779da7bb4466c59a478c095ee0342c6932c482426e3331bf472c8296c31d30`.

Purpose: determine the minimum scalar grouped-int8 precision needed at Layers
24 and 47 after D1 proved group32 is depth-sensitive. D2 is diagnostic only;
there is no performance timing and no quality-pass decision.

Characterize `group32`, `group16`, and `group8`. Group32 is the frozen control.
Group16/group8 retain the exact symmetric int8 + F32-scale grammar and rounding
rule; only group granularity changes. F32 is the fallback comparator, not a new
packed artifact.

Layer 24 contexts:
- canonical F32 prefix;
- Layer-0 group32 prefix.

Layer 47 contexts:
- canonical F32 prefix;
- original R2.2 failing prefix with Layers 0+24 group32.
For each layer/group/context, compute candidate and canonical-F32 routed expert
outputs from the same post-norm input and router, over the complete frozen
`short_thai` prompt. Record maximum local absolute error and router identities.
The frozen local acceptance limit is `<=0.001`.

Selection is prospective and deterministic: per layer, inspect groups in
`32 -> 16 -> 8` order and select the first group that passes every context. If
none passes, select canonical F32 fallback. This selection only proposes a
hybrid candidate for a later full held-out quality re-entry.

Expected packed bytes per layer:
- group32: `679,477,248` (existing control);
- group16: `754,974,720`;
- group8: `905,969,664`.

Before any D2 measurement, extend only the scalar characterization seam, create
and freeze all four new Layer24/47 group16/group8 artifact identities, and
freeze the measurement harness/execution. No native-kernel change, retries,
post-result group sizes, performance claims, or R2.2c authorization are allowed.
