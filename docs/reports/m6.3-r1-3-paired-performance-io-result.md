## Resource and correctness gates

All samples retained final argmax `0`, correlated ETW, valid memory observations, exact candidate identity/accounting, and the configured F32 cache ceiling. Maximum observed working set was 142,696,448 bytes and maximum private bytes were 138,760,192 bytes, far below the 17,179,869,184-byte review ceiling.

## Interpretation

The packed Layer-0 group-32 path reduces logical bytes consistently, but the current direct safe-Rust dequantization/consumption path does not turn that reduction into consistent TTFT, prefill, decode, working-set, private-byte, or physical-I/O benefit. Median timed wall is worse in both conditions and pair directions are mixed.

This result is deliberately limited to the measured Layer-0 vertical slice with unchanged F32 Layers 1-47. It neither proves nor estimates an all-layer speedup.

## Decision boundary

R1.3 closes as `valid_measurement_set` and authorizes R1.4 review. ADR 0077 records the measurement result; ADR 0078 performs the promotion decision.
