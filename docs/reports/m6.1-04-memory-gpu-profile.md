# M6.1-04 usable memory and GPU backend discovery

## Result

The Windows host has two detected display adapters: NVIDIA T500 and Intel Iris
Xe Graphics. NVIDIA telemetry reports 4 GiB for the T500. CUDA and Vulkan
tooling are present, and the DirectML system library is present. None is a
usable colibri backend: M6.1 implements no GPU backend and M6.3 has not
reviewed or approved one. Therefore the admissible VRAM budget is zero and
host/device transfer was explicitly not run.

This separates device inventory from runtime capability. It does not reject a
future GPU candidate; it prevents an unmeasured or unimplemented candidate from
being selected by M6.2.

## Backend evidence

CUDA telemetry was read from nvidia-smi. DirectML detection uses the Windows
system library plus display-adapter inventory. Vulkan detection checks for
vulkaninfo. Their presence proves only that the host has potential candidate
surfaces. No GPU compute, transfer benchmark, new dependency, or backend
implementation was introduced.

The machine-readable evidence is
docs/benchmarks/m6.1-04-memory-gpu-profile-v1.json. It records every transfer
field as not_run with a reason, and marks usable VRAM as zero.

VRAM recommendation, or a transfer result without the M6.3 backend review.
