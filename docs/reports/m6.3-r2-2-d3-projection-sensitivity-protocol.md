# M6.3-R2.2-D3 projection-sensitivity protocol

## Purpose

Determine whether the Layer24/47 group32 routed-output error is concentrated in
specific expert projections so a projection-level mixed representation can be
designed without guessing a new group size or bit width.

D3 is diagnostic only. It makes no quality or performance claim and cannot
authorize R2.2c.

## Frozen matrix

Fixture: `short_thai`. Backend: scalar group32 only.

Contexts are unchanged from D2: Layer24 under F32 and Layer0-group32 prefixes;
Layer47 under F32 and the original Layer0+24-group32 failing prefix.

At each target input/router, calculate an all-F32 comparator and all seven
non-empty packed projection subsets in this fixed order:
`gate+up+down`, `gate+up`, `gate+down`, `up+down`, `gate`, `up`, `down`.
Omitted projections use the canonical F32 projection for the same expert.
For each context/variant record routed-output max-abs per prompt position, maximum
over the complete prompt, final router identity, output finiteness, packed
projection count, and modeled expert/layer bytes. Target variants are diagnostic
branches only and are not propagated to later layers.

## Frozen decision

The local limit remains `0.001`. Per layer, inspect variants in the fixed order
above. Select the first variant passing every frozen context; if none passes,
select canonical F32. This prefers more packed projections and uses the written
order only as a deterministic tie-break among equal packed counts.

Modeled layer bytes are:

- 3 packed: `679,477,248`
- 2 packed + 1 F32: `1,258,291,200`
- 1 packed + 2 F32: `1,837,105,152`
- all F32 fallback: `2,415,919,104`

No new artifact is created in D3. A selected hybrid is only a hypothesis and
requires a separate converter/artifact freeze, full held-out quality re-entry,
and quality PASS before any performance work.
