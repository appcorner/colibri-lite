# M6.3-06 Stop/Go Review

## Decision

**NO-GO.** The Layer-0 group-128 INT8 safe-Rust candidate is stopped at the
vertical slice. It must not be extended to 48 layers, selected as a production
precision policy, or used to begin M6.4.

## Gate review

| Gate | Evidence | Result |
| --- | --- | --- |
| Direct quantized consumption | M6.3-02 records zero F32 projection/expert materialization in the candidate path. | Pass |
| F32-sensitive path and reference | M6.3-03 preserves router, norms, attention, residuals, cache, dense path, and independent F32 comparison. | Pass |
| Bilingual structural/output checks | M6.3-04 has exact final router IDs, matching argmax, and 20/20 top-ID overlap for English and Thai. | Pass, limited fixture scope |
| Numerical quality admission | English fixed-logit drift is `1.69116020202636719e-1`; no candidate-specific tolerance/admission rule was justified. | Fail |
| Repeated material end-to-end benefit | M6.3-05 median decode is cold `0.0203946244` and warm `0.0209938461` tok/s; Layers 1--47 remain scalar F32 bottlenecks. | Fail |
| RAM / physical-I/O evidence | Explicit payload accounting is 87,392,256 bytes and VRAM is zero, but process working-set peak and physical per-process reads are not measured. | Fail |
| No hidden F32 candidate expansion | The candidate directly consumes INT8/scales; F32 Layer-0 execution was used only as a separate reference checkpoint calculation. | Pass |

## Rationale

The candidate produces correct routing and stable frozen token choices for the
two bilingual fixtures, but that does not overcome the material English logit
drift or demonstrate an end-to-end performance benefit. Warm-cache removal of
68,124,672 candidate logical bytes does not move the scalar full-model decode
rate materially. Required physical-I/O and working-set evidence is also absent.

Changing tolerances to admit this result would violate the frozen F32
comparison policy. Adding a GPU backend, SIMD, FFI, or an all-layer quantized
path to compensate is deferred and not authorized by this review.

## Consequence

M6.3 is closed with a stop decision, not a promotion. M6.4 is blocked and must
not start. A future proposal needs a separately reviewed ADR and task plan;
until then, the executable `reference-f32-v1` remains the only admitted path.
