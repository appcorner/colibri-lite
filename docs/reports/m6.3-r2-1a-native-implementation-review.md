# M6.3-R2.1a native packed-projection implementation review

Status: implementation complete; R2.1b quality is next. No official performance timing was run.

## Implemented boundary

- Added feature `m6-3-r2-native`; default runtime remains scalar.
- Added one MSVC C translation unit for group32 gate/up/down projection math.
- Kernel uses AVX2 i8 widening and FMA against unchanged f32 scales/input.
- Rust performs runtime AVX2+FMA detection and falls back to scalar otherwise.
- Group64 requests always remain scalar.
- Routing, loading, SiLU, weighted accumulation, cache policy, and artifact format are unchanged.
- No requantization, persistent repack, threading, GPU path, or AVX-512 was added.

The kernel allocates no heap memory and has no static state. Additional native
scratch is 0 bytes, persistent prepack is 0 bytes, and complete F32 weight
materializations remain 0.
## Dependency and unsafe review

ADR 0088 admits `cc = 1.4.4` as build-only. Cargo resolved transitive build
dependencies `find-msvc-tools 0.1.11` and `shlex 2.0.1`. The workspace unsafe
lint changed from `forbid` to `deny` solely so the isolated `r2_native.rs`
module can override it locally. No other Rust source contains a new unsafe block.

Before FFI, Rust validates CPU features, dimensions, exact buffer lengths,
finite values/scales, nonnegative scales, group size 32, and the existing
forbidden -128 payload rule. Buffers stay Rust-owned and pointers do not escape.

## Correctness evidence

Native projection tests cover scalar comparison, invalid-length rejection, and
output canaries. Packed-projection tests cover explicit native/scalar selection,
group64 scalar fallback, and a loaded expert executing all three native
projections with zero F32 weight materialization. The expert-level synthetic
native/scalar max-abs guard uses the pre-registered 0.001 Layer-0 bound.
