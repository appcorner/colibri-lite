# M6.3-R2.2-D4D4 Group8 Hybrid Held-Out Quality Protocol

D4D4 is a quality-only re-entry for the exact D4D3-selected policy: Layer0 group32 gate/up/down, Layer24 F32 gate/up plus group8 down, Layer47 and every other layer canonical F32.

Each held-out fixture (`short_english`, `short_thai`) executes one scalar-hybrid run and two mixed-backend runs. Mixed backend changes only Layer0 from scalar group32 to the existing AVX2+FMA group32 kernel; Layer24 group8 remains scalar.

Frozen gates are unchanged from D4D2: exact two-token generation, prompt top-20 order, prompt argmax, exact router guards at Layers 0/24/47, finite logits, existing compact F32 logit envelope, scalar candidate/F32 local max-abs <= `0.001` at Layers 0/24, mixed/scalar Layer0 max-abs <= `0.001`, mixed/scalar prompt-logit max-abs <= `0.002`, and exact mixed-run repeatability.

The harness may decode a complete F32 Layer24 expert only as the same-input/router semantic comparator. This invalidates resource/I/O/working-set inference from D4D4.

No automatic retry, threshold relaxation, group reselection, new group size, higher-bit representation, native group8 implementation, historical R2.2c reuse, or performance timing is allowed.

A PASS authorizes only D5 hybrid artifact/layout and backend/performance-contract design. D5 implementation, all-layer rollout, and M6.4 remain blocked.
